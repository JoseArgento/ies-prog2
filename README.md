# Programación 2 — Casos prácticos en C# / Windows Forms

Colección de ejercicios desarrollados para la materia **Programación 2** del IES.
Cada caso es una aplicación de escritorio en **Windows Forms (C#)** que trabaja un
tema puntual: entrada de datos, controles de selección, validaciones, grillas y
manejo de eventos.

---

## 🛠️ Tecnologías

- **Lenguaje:** C#
- **Framework:** .NET / Windows Forms
- **IDE:** Visual Studio

---

## 📂 Casos

| # | Caso | Qué practica |
|---|------|--------------|
| 1 | Presentación personal | Controles básicos, labels y eventos de botón |
| 2 | Calculadora básica | Operaciones aritméticas y conversión de tipos |
| 3 | Conversor de unidades | Cálculos, ComboBox y formato de resultados |
| 4 | Registro de alumno | RadioButton, CheckBox, ComboBox y validaciones |
| 5 | Login | Verificación de credenciales y mensajes de error |
| 6 | Agenda de contactos | Carga y visualización de registros |
| 7 | Sistema de ventas | DataGridView, cálculo de subtotales y total general |
| 8 | Gestor de tareas | Grilla con estados, alta, eliminación y completado |
| 9 | Farmacia y medicamentos | Gestión de productos y stock |
| 10 | Sistema integral de gestión | Integración de los temas vistos en un solo proyecto |

---

## ▶️ Cómo ejecutar

1. Cloná el repositorio:
   ```bash
   git clone https://github.com/oseArgento/ies-prog2.git
   ```
2. Abrí la solución (`.sln`) del caso que quieras probar con Visual Studio.
3. Presioná **F5** para compilar y ejecutar.
